# Papercraft Chess for All

## 概要 (Overview)

このプロジェクトは、3Dモデルからペーパークラフト用のチェスセットを生成するためのツール群です。視覚障碍を持つ方でも楽しめるよう、触覚的なフィードバックを考慮したデザインの生成も目的の一つとしています。

最終的な出力は、印刷して組み立てることができるPDFファイルです。

## ディレクトリ構成 (Directory Structure)

- **/`models`**: チェスの駒やボードの元となる3Dモデル（`.blend`, `.obj`）が格納されています。
- **/`PDF`**: スクリプトによって生成されたペーパークラフト用のPDFファイルが保存されています。
- **/`photo`**: 駒の表面に貼り付けるテクスチャ画像や、デザインのサンプル画像などが格納されています。
- **/`scripts`**: PDFを生成・加工するための一連のスクリプト群です。各スクリプトの詳細は、`scripts/README.md`を参照してください。

## 基本的なワークフロー (Basic Workflow)

1.  **モデル準備**: `/models`ディレクトリに`.obj`形式の3Dモデルを準備します。
2.  **PDF生成**: `/scripts`内のスクリプトを実行し、モデル、色、スケール、画像などを指定してPDFを生成します。
3.  **PDFクリーンアップ**: 必要に応じて、後処理用スクリプトでPDFを整形します。
4.  **完成**: `/PDF`ディレクトリに出力された最終的なPDFを印刷し、組み立てます。
