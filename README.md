# PDF線分処理ツール

## 概要

このツール群は、PDFファイルに含まれる描画データ（特に線分）を処理するためのPythonスクリプトを提供します。極端に短い線分（点として扱われるもの）を検出し、それらを一括で除去する機能を持っています。


## ファイル構成

- **`process_pdf.py`**
  - **役割**: 指定されたPDFファイル内のすべてのページをスキャンし、極端に短い線分を除去した新しいPDFを生成します。元の線分の色や太さは保持されます。
  - **出力**: `(元のファイル名)_treated.pdf`という名前の新しいPDFファイル。

- **`confirm_pdf.py`**
  - **役割**: 指定されたPDFファイル*を検査し、極端に短い線分（点）が存在するかどうかを確認します。存在する場合、コンソールにメッセージを出力します。複数ページの処理は想定していません．


## 使用方法

### 1. 短い線分の除去 (`process_pdf.py`)

PDFをクリーンアップしたい場合に使用します。

1. ターミナルで以下のコマンドを実行します。
   ```bash
   python3 process_pdf.py
   ```

2. プロンプトが表示されたら、処理したいPDFのファイル名（例: `pawn2.pdf`）を入力してEnterキーを押します。

3. 処理が完了すると、同じディレクトリに `(ファイル名)_treated.pdf` が作成されます。

### 2. 短い線分の存在確認 (`confirm_pdf.py`)

PDFに短い線分が含まれているかを確認したい場合に使用します。

1. ターミナルで以下のコマンドを実行します。
   ```bash
   python3 confirm_pdf.py
   ```

2. プロンプトが表示されたら、確認したいPDFのファイル名を入力してEnterキーを押します。

3. 短い線分が見つかった場合、`existing point...`というメッセージがコンソールに表示されます。


## ワークフロー例

1. **確認**: まず`confirm_pdf.py`を使って、元のPDF (`original.pdf`) に短い線分が含まれているかを確認します。
2. **処理**: 短い線分が見つかった場合、`process_pdf.py`を実行して `original.pdf` を処理し、`original_treated.pdf` を生成します。
3. **再確認**: `confirm_pdf.py`を再度実行し、今度は `original_treated.pdf` を入力して、短い線分が正常に除去されたことを確認します。
