# スクリプト仕様 (Scripts Specification)

このディレクトリには、`.obj`モデルからPDFを生成・加工するためのスクリプト群が格納されています。

## 主要なスクリプトと機能

### PDF生成スクリプト

- **`treatPDF_sizing.py`**
  - **役割**: `.obj`モデルを読み込み、面を単色で塗りつぶしたPDFを生成します。オプションで、指定した位置に画像（マーク）を追加することも可能です。
  - **主な用途**: 特定の色（例: 紫、黄色）で駒をデザインする場合に使用します。

- **`treatPDF_fillpic.py`**
  - **役割**: `.obj`モデルの面全体を画像で埋めたり、指定した位置に画像（マーク）を配置したPDFを生成します。
  - **主な用途**: 木目調や特定の柄など、テクスチャを持つ駒をデザインする場合に使用します。

### PDF後処理スクリプト

- **`process_pdf.py`**
  - **役割**: PDF内の極端に短い線分（3Dモデルからの変換時に発生しがちな「点」）を除去し、クリーンなPDFを再生成します。
  - **入力**: ターミナルでファイル名を指定します。
  - **出力**: `(元のファイル名)_treated.pdf`

- **`confirm_pdf.py`**
  - **役割**: PDF内に短い線分が存在するかどうかを検査します。
  - **入力**: ターミナルでファイル名を指定します。
  - **出力**: コンソールに`existing point...`というメッセージを表示します。

### ユーティリティ

- **`piece.py`**: チェスの駒に関するデータや設定を管理します。
- **`process.sh`, `process_2.sh`, `process_3.sh`**: 上記のPythonスクリプトを連続して実行し、一連のPDF生成処理を自動化するためのシェルスクリプトです。
