# スクリプト仕様書

このドキュメントは、`treatPDF_fillpic.py` および `treatPDF_sizing.py` の2つのスクリプトの機能と処理の流れについて解説します。

---

## `treatPDF_fillpic.py` の仕様

このスクリプトの主な目的は、**.objモデルの「面」を画像で埋める、または指定した位置に画像の「マーク」を配置すること**です。

### 処理の流れ

`plot_obj` 関数内の処理は、以下の順序で実行されます。

#### 1. 動作モードの選択
スクリプトは最初に、実行したい処理をユーザーに選択させます。

```python
print("1: 面全体を画像で埋める")
print("2: 指定した位置にマーク（画像）を配置する")
mode = input("選択 (1 or 2): ").strip()
```
ここで入力された `mode` の値（`'1'` または `'2'`）によって、以降の処理が大きく分岐します。

#### 2. ユーザー入力
- まず、両方のモードに共通する**スケール**が尋ねられます。
- **モード1** を選択した場合：面に貼り付ける**画像ファイルのパス**が要求されます。
- **モード2** を選択した場合：マーク用の**画像パス**、配置先の**中心座標(X, Y)**、マークの**横幅**が要求されます。

#### 3. 描画領域の準備
`matplotlib` を用いて、A3サイズの描画領域（`fig`, `ax`）を準備し、ユーザーが指定したスケールに基づいてモデルが収まるように描画範囲（`xlim`, `ylim`）を計算・設定します。

#### 4. 描画処理

##### モード1: 面を画像で埋める場合
- `if mode == '1' and faces and image_path:` のブロックが実行されます。
- `for face_indices in faces:` ループで、モデルの各「面」を一つずつ処理します。
- 各面について、その頂点から `Polygon` オブジェクトを作成し、これを**クリッピングパス（切り抜きマスク）**として設定します (`clip_poly`)。
- `ax.imshow(...)` で画像を描画しますが、このとき `im_face.set_clip_path(clip_poly)` を使うことで、画像の表示範囲がその面の形状に合わせて切り抜かれます。
- `origin='upper'` により、画像の向きが正しく表示されます。

##### モード2: マークを配置する場合
- `if mode == '2' and mark_img is not None:` のブロックが実行されます。
- ユーザーが入力した中心座標と横幅、そして画像の縦横比から、画像を描画すべき範囲（`extent`）を計算します。
- `ax.imshow(..., zorder=10)` を一度だけ呼び出し、他のどの要素よりも手前（`zorder=10`）にマーク画像を描画します。
- こちらも `origin='upper'` で画像の向きを正しく保ちます。

##### 共通の描画処理
- モードに関わらず、モデルの**線（l）**と**面の境界線（f）**が `ax.plot()` で描画されます。
- 孤立点がある場合、`if unreferenced_vertices_coords:` ブロックが実行され、`Circle((ux, uy), ..., facecolor='black')` によって、各孤立点の位置に**黒く塗りつぶされた円**が描画されます。

#### 5. PDFの保存
最後に `plt.savefig(pdf_filename)` が呼び出され、これまでの描画内容がすべて一つのPDFファイルとして保存されます。

## `treatPDF_sizing.py` の仕様

このスクリプトの主な目的は、**.objモデルの「面」を単色で塗りつぶし、その上にオプションとして画像の「マーク」を配置すること**です。

### 処理の流れ

`plot_obj` 関数内の処理は、以下の順序で実行されます。

#### 1. 必須のユーザー入力
スクリプトは最初に、常に必要となる**スケール**と、面の塗りつぶしに使う**色のRGB値**をユーザーに尋ねます。
```python
user_scale_cm_per_unit = float(...) 
fill_color = (r / 255, g / 255, b / 255)
```

#### 2. 面の単色塗りつぶし
描画領域の準備後、`if faces:` ブロック内で、**常に**面の塗りつぶし処理が実行されます。
`for face_indices in faces:` ループで各面を処理し、`Polygon(..., facecolor=fill_color, ...)` を使って、ユーザーが指定した単色で面を塗りつぶします。

#### 3. マーク配置の選択（オプション）
単色での塗りつぶし設定の後、スクリプトはユーザーに追加でマークを配置するかどうかを尋ねます。
```python
print("\nマーク（画像）を配置しますか？")
choice = input("選択 (y/n): ").lower().strip()
```
ここで `'y'` が入力された場合のみ、`place_mark` フラグが `True` になります。

#### 4. マーク配置の実行（条件付き）
- `if place_mark:` ブロックが実行されます（ユーザーが 'y' を選択した場合のみ）。
- このブロック内の処理は、`treatPDF_fillpic.py` の**モード2と全く同じ**です。マーク用の画像パス、座標、幅が尋ねられ、`ax.imshow(..., zorder=10, origin='upper')` によって、単色で塗りつぶされた面の上にマークが上書き描画されます。

#### 5. 共通の描画処理
- `treatPDF_fillpic.py` と同様に、モデルの**線**と**面の境界線**が描画されます。
- 孤立点がある場合、同様に**黒く塗りつぶされた円**が描画されます。

#### 6. PDFの保存
最後に `plt.savefig(pdf_filename)` が呼び出され、最終的な描画内容がPDFとして保存されます。

---

### まとめ：2つのスクリプトの主な違い

- **`treatPDF_fillpic.py`**: **画像が主役**のスクリプト。「面全体を画像で埋める」か「マークを置く」かを最初に選択します。
- **`treatPDF_sizing.py`**: **単色が主役**のスクリプト。常に面を単色で塗りつぶし、「マークを置く」のはあくまで追加のオプションです。
